# Credit-Card-Fraud-Detection
🕵️‍♂️ Fraud Detection Model using Machine Learning This project focuses on building a fraud detection model using supervised machine learning techniques. The goal is to accurately classify transactions as fraudulent or legitimate based on historical data and relevant features.

📌 Project Overview
Fraudulent transactions pose a significant challenge in finance and e-commerce. Traditional rule-based systems often fail to detect complex patterns. This project leverages machine learning to learn these patterns automatically and predict fraud with better precision.

✅ Features
   > Preprocessed input data for training.

   > Encoded categorical variables using Label Encoding.

   > Applied various models, and saved the best performing one.

   > Balanced the dataset using SMOTE to handle class imbalance.

   > Evaluation using metrics like accuracy, precision, recall, F1-score, and ROC-AUC.

   > Saved the final model (Fraud_Detection_Model.jb) and label encoders (label_Encoders.jb) for future use.
